## Requirements
### Requirement: Movements Table Observations Tooltip Positioning

The system SHALL display the observations tooltip below the trigger icon in the movements table.

#### Scenario: Tooltip appears below

- **WHEN** the user hovers over the observations icon in the movements table
- **THEN** the tooltip appears directly below the icon

### Requirement: Tooltip Theme Consistency

The tooltip background and arrow SHALL use theme-compliant colors to ensure visual consistency.

#### Scenario: Tooltip colors match

- **WHEN** a tooltip is triggered
- **THEN** the box background and the pointing arrow use the same theme-compliant color
