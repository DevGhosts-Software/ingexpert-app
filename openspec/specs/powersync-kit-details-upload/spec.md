## ADDED Requirements

### Requirement: PowerSync connector SHALL upload kit detail CRUD entries

The frontend PowerSync connector MUST support upload replay for `kit_details` CRUD entries generated by local inventory kit write flows.

#### Scenario: Kit detail upsert is replayed

- **WHEN** PowerSync emits a `PUT` CRUD entry for table `kit_details` (or compatible alias)
- **THEN** the connector MUST upsert the payload into Supabase `kit_details` keyed by `id`
- **THEN** upload processing MUST continue without unsupported-table errors

#### Scenario: Kit detail delete is replayed

- **WHEN** PowerSync emits a `DELETE` CRUD entry for table `kit_details`
- **THEN** the connector MUST delete the matching Supabase `kit_details` row by `id`
- **THEN** upload processing MUST continue without unsupported-operation errors

#### Scenario: Supabase upload fails for kit details

- **WHEN** Supabase responds with an error while replaying `kit_details` CRUD
- **THEN** the connector MUST throw a table-scoped upload error message that identifies `kit_details` and the affected entry id
